## 已确认的评分差异

| 项目 | 主流水线的 ExecutionAccuracy | 独立参考脚本 ea_cypher.py | 对我们实验的要求 |
|---|---|---|---|
| 无排序的结果行 | Counter 多重集合比较，保留重复次数 | 集合比较，忽略重复次数 | 记录采用哪个版本；同时保留原始返回行 |
| 排序 | 在预测查询文本中查找 `order by`，命中后按行顺序比较 | 始终忽略行顺序 | 正式语义辅助检查应预先确定题目要求；不能由预测是否写出排序决定 |
| 浮点 | 保留到小数点后 9 位 | 保留到小数点后 9 位 | 这是来源实现的数值合同；不能自动认定为错误或擅自改精度 |
| 类型 | Python 值比较会令 True 与 1 相等 | 同样如此 | 原始类型需留档；是否添加类型敏感辅助统计须在预测前固定 |
| 输入长度 | 使用 zip，长度不等时截断 | 按输入记录逐题循环 | 我们须核验 ID、数量和一对一对应，缺失项不能从分母消失 |
| gold 执行失败 | 计为不正确 | 返回 -1；主程序从 evaluated_count 排除 | 报告全量 N、gold 可执行 N、失败原因及作者口径；不能静默筛题 |
| 数据库选择 | compute 默认 `default`；流水线调用未传 db_id | 命令行显式传 database | 必须核验实际图名称和数据身份，不能仅靠结果文件名 |
| 逐题结果文件 | `_save_detailed_results` 将整批 ea 写入每条记录 | 保存失败详情和 gold 可执行 ID | 不把该字段作为逐题 0/1；我们须独立保存逐题原始执行与判分凭据 |

主比较器依据：[metrics.py，第 14–60 行](https://github.com/ldbc/Text2GraphQuery-Driver/blob/ab296fab179e806cd3ad2e659e9f5dc61bd1af3e/impl/evaluation/metrics.py#L14-L60)。参考脚本依据：[ea_cypher.py，第 212 行起](https://github.com/ldbc/Text2GraphQuery-Driver/blob/ab296fab179e806cd3ad2e659e9f5dc61bd1af3e/contrib/standalone_text2graph_scripts/reference/ea_cypher.py#L212)。批量输出依据：[run_pipeline.py](https://github.com/ldbc/Text2GraphQuery-Driver/blob/ab296fab179e806cd3ad2e659e9f5dc61bd1af3e/run_pipeline.py#L189)。这些结论针对固定源码；尚未测量它们对真实数据集分数的影响，不能据此否定论文报告结果。
