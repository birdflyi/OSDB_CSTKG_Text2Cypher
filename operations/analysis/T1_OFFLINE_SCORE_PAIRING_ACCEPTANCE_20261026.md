## 解决的具体问题

固定作者驱动中的`ExecutionAccuracy.compute`用zip遍历两侧列表，长度不同时会截断。此前11项作者行为检查已确认此事；本轮没有重新运行作者模块或恢复逻辑。新组件在进入比较前按`(graph,id)`关联固定清单；缺失项保留UNSENT，重复最终记录、未知ID、任务版本或模型／方法／输入／评分／cohort版本不符均拒绝整批，不选择最后一条或最高分记录。[固定作者源码](https://github.com/ldbc/Text2GraphQuery-Driver/blob/ab296fab179e806cd3ad2e659e9f5dc61bd1af3e/impl/evaluation/metrics.py#L45-L60)。

组件位于`operations/analysis/offline_score_pairing.py`，仅处理调用方提供的离线记录；没有模型、网络、数据库、文件读写或自动修复入口。比较器由调用方显式提供。本轮采用已有类型敏感辅助比较器，仅验证软件行为，不把它称为作者EA，也不因此决定正式评分版本。

## 状态与分母约束

| 情况 | 处理方式 |
|---|---|
| 清单有题、无最终记录 | 保留题位、标UNSENT；已知参考的未决评分会阻止输出完整辅助比例 |
| 同ID在不同图 | 两个复合键分别保留，不因裸ID相同而合并 |
| 重复最终记录、额外ID、任务或版本不符 | 比较前拒绝整批，先审计，不静默挑选或截断 |
| EXECUTED且答案完整、结构有效 | 才计完整答案覆盖；实际比较最终rows，不用计划正确替代答案 |
| 拒答、模型／执行／基础设施错误、截断、未知完成 | 六类分别保留，不算正确；失败不能带一个伪装成功的空answer |
| 有效空答案 | 仍为完整答案，可以比较；不同于失败或未知参考 |
| 参考执行未知 | reference=None；不赋正确／错误分；全题覆盖分母仍保留该位置 |
| 比较器异常或返回非bool | 留SCORING_ERROR／未决分数，不计错误答案，不给出完整辅助比例 |
| 成功记录实际不完整或行宽无效 | INVALID_ANSWER、不计完整覆盖；不是合法空答案 |

完整覆盖分母、已知参考分母、未派发、未决评分和错误答案数分别输出。辅助已知参考比例只有已知参考各位均有可判状态时才给出；该约束不是在未知参考位补0或放宽主指标。正式作者兼容口径、全量指标、未知参考和配对统计仍须按各基准协议冻结后分别报告。

| 固定全量回放场景 | 观察与验收 |
|---|---|
| 参考原样复制为合成最终答案 | 3,815个已知参考与自身相同；11个未知位仍未派发，不产生模型成绩 |
| 逆序提交全部已知记录 | 全部逐位日志与原顺序完全相同 |
| 删除第一个已知位记录 | 仍3,826位置，未派发12，已知参考未决1，辅助比例不输出 |
| 重复一条最终记录 | 整批拒绝，未选择最好或最后结果 |
| 改一个任务摘要 | 整批拒绝 |
| 改一个模型上下文 | 整批拒绝 |
| 改成清单外ID | 整批拒绝 |
| 前六个已知位分别注入六类失败 | 六类各1，完整合成答案3,809；六位均不算正确，分母不变 |
| 给11个未知参考位合成有效空答案 | 覆盖可达3,826，但11位仍无分数；不能变成3,826个正确 |
| 一个已知位答案行宽破坏 | INVALID_ANSWER=1，完整合成答案3,814 |
| 一次比较器异常 | SCORING_ERROR=1，错误完整答案数不因此增加，已知参考比例不输出 |

11/11场景通过。`reference-clone`是软件自我回放，不是3,815道题模型答对，不报告为100%模型EX，也不估计真实错误率、覆盖或效果。注入故障不是实际运行故障率；反复扫描不是更多独立实验。
