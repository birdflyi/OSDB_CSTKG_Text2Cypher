## 11 条参考错误

11 条均在地理图。原 schema 将 `PointOfInterest.capacity` 声明为 STRING，相关参考将它与整数比较。当前引擎报 `STRING vs INT64`。CSV 共 300 行，其中 237 个非空值是整数字符串，63 个为空；非空数值范围为 1–303。

这些错误有原始 schema、CSV、题目 ID、查询哈希和原生响应作证。它们不是模型调用失败。没有补造答案，没有给参考偷偷加入数值转换，也没有据此认定所有其他引擎版本都无法执行。

下一阶段拟保留全部 3,826 个模型预测位置。在正式预测前固定：已可执行参考的 EX 范围、全量返回覆盖、不可评分参考计数及统计。当前可执行参考为 3,815 条，另外 11 条的真实正确性未知；不能把未知 gold 计成已知模型错误或成功。`text2gql_reference_cohorts_provisional_20261026.json` 只是与模型结果无关的来源清单，**尚未通过最终指标冻结**。

作者论文另用 2,783 个跨 TuGraph／Spanner 可执行例子，其确切 ID／版本仍未对齐。不能将该 reported 行直接排在本地全量成绩旁比较高低。

## 数值与导入核验

最初按 Python 的正确舍入十进制转浮点逐位检查时，共发现 427 个投影行有差异。它们的数量分布为：Production 101、IT Asset 0、BOM 205、Geography 56、Financial 65、Twitter 0。

固定源码的 CSV 路径经 `column_parser.h`、`field_data_helper.h` 调用 `fma-common/text_parser.h` 的十进制解析。它逐位累加小数位，运算顺序与 Python 的十进制转换不同。我们保留了第一图 101 个差异值（1–2 ULP），并以该源码运算顺序逐位复现其原生结果。后续完整六图以**原生解析器的精确位模式**检查，同时保留与正确舍入十进制的差异统计。没有增加容差，没有改变模型答案评分，也不声称原生导入实现等于数学上正确舍入。

源码依据：[字段解析调用](https://github.com/TuGraph-family/tugraph-db/blob/4a1c8fb69b7879396f36e491b125d297c7ca79dd/src/core/field_data_helper.h#L673-L678)、[十进制解析的运算顺序](https://github.com/TuGraph-family/tugraph-db/blob/4a1c8fb69b7879396f36e491b125d297c7ca79dd/include/fma-common/text_parser.h#L521-L556)。本地缓存保留 Git blob 与 SHA 核验；不把源码对应关系写成未经证实的二进制签名证明。

所有原始失败仍保留：初次小图导入的虚拟地址空间限制、带引号标签的查找失败，以及第一图严格十进制检查。纠正数据核验器不等于改掉旧结果；每版代码、输入和响应都有独立记录。

## 独立小图揭示的后端边界

| 固定检查 | 当前原生结果 |
|---|---|
| 同一 MATCH 内关系不能重用 | 符合预期 |
| 平行边的重复次数 | 符合预期 |
| DATE 条件 | 默认前端符合预期 |
| 连续 MATCH／OPTIONAL MATCH | 测试写法报 AddClause 未实现；固定源码也有相关限制，不能按 Neo4j 语法直接迁移 |
| NULL 否定 | 属性确认为真实 NULL，但默认前端筛选结果与原 Neo4j 三值逻辑预期不同 |
| DATETIME 构造 | 固定 ISO-T 写法失败；额外诊断中的空格分隔格式成功 |
| 中文值往返 | 额外诊断成功 |

原八项检查在默认前端符合 3 项；旧前端的诊断复测符合 2 项。默认前端仍沿用发行包默认设置，不按 Ours 成绩选择。额外诊断不能包装成原八项全部通过。合计执行 32 次小图查询，原始预期未改。

连续 MATCH 的当前限制也可定位到固定源码 [clause.h](https://github.com/TuGraph-family/tugraph-db/blob/4a1c8fb69b7879396f36e491b125d297c7ca79dd/src/cypher/parser/clause.h#L296-L301)；这不是模型能力结论。

这些证据说明：**不能将原 Neo4j 服务直接标为 TuGraph 通用实现。** 后续需在训练／独立开发材料上完成通用后端适配，并给 Direct 与 Ours 相同的方言和类型信息。不得从 TEST 错题逐条增加工具。此处保留具体后端边界，不扩展一般 NF 理论。
