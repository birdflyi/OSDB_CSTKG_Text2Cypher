# Text2GQL schema、实体身份与集合服务适配验收

2026-10-26。本轮属于 T1 的离线实现准备；没有新的模型调用或正式预测，没有修改 CypherBench 冻结版或测试结果。

## 可接受的交付

在独立分支 `codex/ch7-t1-tugraph-adapter` 上，方法开发版本更新为 `typed-services-dev-0.4-native-identity`。

1. 从原生 `import_config.json` 读取实体主键、真实属性、原始类型和有向边端点约束。身份是实体实际声明的主键，公开给服务使用；不向原图添加 `eid/aliases/description/rid`，不根据 CSV 值猜测或修正字段类型。
2. 六图 schema 全部核对，共 **46 类实体、64 个有向边签名**，主键均为 STRING。配置 SHA 与先前封存的六图计划一致，属性集合及原始类型逐项一致。Geography 的 capacity 仍保留 STRING，没有借适配修参考答案。
3. 集合组合和实体分组改用声明的真实主键。相同显示名称不合并成一个实体；union/intersection/difference 的键必须是投影出的主键，载荷必须依附同一实体。不能用 name 等普通属性伪装主键。
4. 同一有效计划可以运行条件性摘要与正确全明细。正向、不同字面量的同字段相等条件仍用于不相交证明；重叠、否定等条件保留完整主键集合计算。没有新增胜率选择规则。
5. 字符串主键经原生小图实际执行验证。整数主键只完成本地类型和组合检查；不把 True、1、"1"、1.0 当作同一主键，不宣称已测量原生整数主键。
