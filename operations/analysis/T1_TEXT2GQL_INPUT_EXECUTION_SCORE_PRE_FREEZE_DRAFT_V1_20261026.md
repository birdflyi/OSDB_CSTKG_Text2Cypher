# Text2GQL 正式预测前协议草案 v1

状态：准备草案，**不是正式冻结、预算批准或运行准入**。所有版本与具体指标入口须进入新冻结清单后才可正式预测。

## 输入合同

两条模型路径同底模、同 schema/图快照、同真实主键、同最多12项候选、同方言提示、同模型参数与完成 token/读取超时。已实现前五项的输入构造和字节一致性；真实 runner 与模型参数一致性尚待接通和 TRAIN 验证。

Direct 输出一般原生只读 Cypher；Ours 输出有限 IR。Direct 不受 IR 能力范围限制；两者都保留拒答、错误、截断与全部尝试。有限 IR 的多重集、实体分组、NULL、时间及 OPTIONAL 语义保持，超出能力不能换题或回退 Direct。

任务入口只提取 ID、图名、initial_question。initial_gql、答案、difficulty、source 及评测标签不进入模型。自然语言版本范围固定为已缓存的六包 initial_question，全部源均为 AT2G-Synth；不称人工任务或抽象改写轨道。

## 执行与反馈合同

模型完成额度/读取超时先沿用既有开发起点，在 TRAIN/独立开发材料验收后冻结；数据库预算与输出上限另外登记，不能将原生数据审计的超时当正式查询时限。两条路径使用相同单次行/字节限制和只读权限。

每条路径最多一次非 gold 执行反馈；有效但错误的答案不根据 gold 修复。Direct 首轮与反馈版本共享。Ours 正确全明细和简单安全策略只作为共享计划的控制，不冒称独立模型。

全部物理模型尝试记录，原生 SQL、候选构建/检索、传输/编译/组合/校验、错误/重试/未知 usage 单列。模型同体请求至多3次，间隔至少10秒，连续3次基础设施失败停止批次；原生语法/未实现错误与传输故障分开。

未知请求先核验日志/进程/检查点，不盲目重发；旧锁和既有服务规则保持。有界原生执行、稳定请求、非gold反馈builder及有限计划桥接已通过独立开发验收；外层SQL/批次停止、模型/一次反馈持久账本仍待集成，不能仅因基础件通过就开跑。

## 分母和参考合同

- 保留全量 **3,826 个任务位置**，计划均生成预测，不按难度或方法成败选择范围。
- 其中预先参考审计的 **3,815 个可执行参考**可产生已知的最终答案比较；11条 Geography 类型冲突仍是未知参考，不能计为模型正确/错误或偷偷修 gold。
- 全量派发、完整答案覆盖、拒答和失败始终报 N=3,826；EX 的实际可评分分母及未知参考数同时明示。
- 当前仓库六包与论文报告的2,783共同子集尚无完整 ID/版本映射；不与其 reported 数字直接排名。

## 评分合同：待核验后锁定

作者固定代码中 OOP Counter 与 standalone set 两入口不同，排序触发、重复行、浮点和错误分母也不同。正式前明确采用哪个公开入口、是否为严格作者模式，以及任何本地协议差异，分别命名，不在预测后挑较高分的入口。

当前已实现的类型敏感比较仅为辅助诊断，不默认作为主指标；原生成功执行不等于 EX。排序检查、题族/重复相关性和配对统计须在预测前固定；不能由某个方法生成的顺序选择更宽松的评测。REST 原样保存 DATE/DATETIME 字符串与 bool/int 类型，不推断未验证的 Bolt 等价。

参考语义/输出表示审计可读取既有参考响应，但此数据分支与输入/方法开发隔离；不得因此逐题加工具或事后选分母。
