## 3. 标签不能相互代替

| Manual TEST 字段组合 | 记录位置数 | 含义边界 |
|---|---:|---|
| logical=空白 | 428，全部在 covid | 没有由本轮补写或推断标签 |
| logical=1，result=0 | 206 | 非空结果不是语义标签的同义词；不能因空结果直接删掉 |
| logical=0，result=1 | 8 | 能返回结果也不能据此认为语义正确 |
| result 字段缺失 | 859，covid 与 er | 不能填成 0，也不能填成 1 |

作者 annotation_protocol.txt 使用 `manual [0/1]` 名称，实际这些 TEST 文件使用 `logical [0/1]`。协议文字把 result 解释为是否检索到结果，但不足以单凭字段名确定正式论文筛选合同。自动 schema／runtime 校验标记也不能用来补写 428 条空白人工标签。

因此，1,829 是盘点记录数；1,316 是当前 logical=1 的标签计数；两者均尚未被我们接受为正式 EX 分母。需要对齐论文评测轨道、参考语义及实际图执行，再在预测前固定纳入规则。

## 4. 对后续 T1 的具体要求

1. 每个具名权重或 ICL 版本登记训练文件、划分、示例及图来源；分别核验与目标 TEST 的重叠。不能把一个 checkpoint 无条件复用于所有轨道。
2. 将 Manual／Automated 的主结果、数据来源、分母和覆盖分开；相同题不能假装是新增独立域或独立样本。
3. 保留全量盘点与已发现异常。不根据 Ours 胜负改变图、题目或标签。
4. 继续核验 dump、schema、作者论文轨道与参考答案。该审计没有证明数据库答案正确，也不证明任何模型从未接触这些数据。
5. 现有 12,000 次额度仍只覆盖 CypherBench。MindTheQuery 范围确定后另列资源和调用需求，不使用现有余额启动。
