## 这些数字能说明什么

1. 对“公开数据只有图 schema 声明了时间与边属性，题目是否涉及这些内容”这个准备问题，我们已有可追溯的词面证据。BOM、生产过程、IT 和社交图存在仅边上声明的属性名访问，值得继续核验边属性语义；六图都有日期／时间属性名访问。
2. 已逐图查看按 ID 排序首个相关命中的原查询，共十个例子。它们包括时间过滤、返回时间字段、按时间排序、边属性投影、边属性过滤或聚合。这是少量直接检查，不是全量语义标注。
3. 一个 Financial Payment 例子只是返回 `completed_at`，并未按时间过滤。因此不能将 498 直接写成“498 道时序推理题”。年份整数、日期字符串、间接别名和其他时间表达也不一定被该词面规则捕获。
4. 属性名访问没有做完整变量绑定与类型检查；函数和关键字也不是完整语法树。不能据此断言参考查询正确、当前服务支持该题，或某个摘要机制可安全适用。COUNT、DISTINCT、OR 或 UNION 出现均不足以证明摘要路径有优势。
5. 显式 LIMIT 属于公开参考工作负载的盘点，不据倍数或出现次数认定系统被默认截断；后续必须分别检查请求语义、参考查询与实际执行限制。
