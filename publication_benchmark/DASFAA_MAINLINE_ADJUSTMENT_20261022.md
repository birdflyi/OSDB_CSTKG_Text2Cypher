# DASFAA 主线调整：我们现在做什么

日期：2026-10-22。主目标：DASFAA 2027 Research 正式长文。当前证据还不足以声称方法整体更好。本次调整研究主线和审阅稿，不修改冻结系统、题目、参考答案或评分。

| 内容 | 现在的处理 |
|---|---|
| 核心问题 | 受控接口如何影响图查询的正确完成、错误返回、拒答、覆盖范围和成本 |
| 数据库机制 | 区分底层信息不足、控制器表达限制、模型语义映射错误；未知原因保留未知 |
| 主对照 | 保留强直接 Cypher G、协议控制 P、信息接口扩展 I；相同修复预算 |
| 主证据 | 独立任务的真实图答案；两个留出项目；能区分错误查询的反例；完整尝试成本 |
| 开发结果 | 用于解释机制和检查回归，不充当独立泛化结果 |
| 旧稿静态与修复结果 | 13/13 静态、24/24 gold-guided 修复退出主要效果贡献；原文件保留 |
| 服务层与交互层 | 保留两层设计动机；一次人工两调用组合可行，不等于模型已能规划 |
| 暂不声称 | 全面更准、比 RAG 更便宜、真实用户更易用、任意 OSS 查询通用 |

## 证据缺口与执行顺序

| 顺序 | 缺什么 | 我们怎么补 |
|---|---|---|
| 1 | 真实任务的稳定执行条件 | 保留当前唯一低频完整请求 curl 探测；不重复启动，不把诊断算成绩 |
| 2 | 冻结独立任务及留出项目的完整结果 | 按记录的准入条件继续既定位置；保留失败、未派发和原有有效输出 |
| 3 | 独立、同能力条件下的优势证据 | 现有新可答目标全部超出单调用语言，先报告覆盖，不能当映射胜负；完成后若仍需新研究，另立冻结阶段，不偷换题 |
| 4 | 超过“小目录覆盖小”的贡献 | 用信息反例、合法组合、实际映射错误区分原因；还不能判定的目标保留未分类 |
| 5 | 可审阅会议第一版 | 已生成 v3，补入两个项目迁移和最新成本；后续按完整证据收口，再组匿名 LNCS 稿 |

当前已知：开发对照未出现稳定总体优势。IoTDB 已知目标迁移全部尝试，Elasticsearch 部分停止；不能用不同分母宣称排名。独立新目标预测仍不完整。337 次新增调用中，78 次用量未知；已知 1,238,600 tokens 不是完整费用。API 原因未定，中文编码不是当前证据支持的解释。
